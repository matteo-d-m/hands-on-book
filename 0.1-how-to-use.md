# How To Use This Website
This website can be used in a passive or an active mode:

- The passive mode does not require anything except reading the website's pages. If this is your choice, you can jump straight to the next page and begin your reading
- The active mode requires installing software, downloading data, and reproduce the preprocessing pipeline in your own computer. If this is your choice, you can follow the instructions in the GitHub repository for the course that inspired this website: [installation instructions](https://github.com/matteo-d-m/brainstim-multimodal#installation-instructions)
